# Time Tracker

A web-based time tracking application that helps you monitor time spent on various tasks across different projects. Generated by Claude Code

## Features

- **Project Management**: Create, edit, and delete projects
- **Task Management**: Create tasks within projects with full CRUD operations
- **Time Tracking**: Start, pause, and stop time tracking for tasks
- **Dashboard**: View summaries of total projects, active tasks, and time spent
- **Data Persistence**: Uses SQLite (Web SQL) with localStorage fallback
- **Responsive Design**: Works on desktop and mobile devices

## How to Use

1. **Open the Application**: Open `index.html` in your web browser

2. **Create a Project**:
   - Go to the "Projects" tab
   - Click "+ Add Project"
   - Enter a project name and save

3. **Create Tasks**:
   - Go to the "Tasks" tab
   - Click "+ Add Task"
   - Enter task name and select a project
   - Save the task

4. **Track Time**:
   - Find your task in the Tasks view or Dashboard
   - Click "Start" to begin timing
   - Use "Pause" to temporarily stop without ending the session
   - Click "Stop" to end the timing session

5. **View Dashboard**:
   - See project summaries with total time spent
   - Monitor currently running tasks
   - View today's total time

## File Structure

- `index.html` - Main application interface
- `styles.css` - Application styling and responsive design
- `database.js` - Database operations and data persistence
- `app.js` - Main application logic and user interactions

## Browser Compatibility

The application uses Web SQL Database when available, with localStorage as a fallback for browsers that don't support Web SQL. Works in all modern browsers.

## Data Storage

- Primary: Web SQL Database (SQLite in browser)
- Fallback: localStorage (JSON-based storage)
- Data persists between browser sessions

## Time Tracking States

- **Stopped**: Task is not running
- **Running**: Task is actively being timed
- **Paused**: Task timing is temporarily stopped
- **Completed**: Task is finished (can be restarted)

Introduction to AI Project Cycle

  • Problem Scoping

Learning Outcome

Identify the AI Project Cycle framework.

Activity

Brainstorming & Goal Setting

  • Discuss various topics within a theme and select one.
  • Draw a mind map of problems related to the topic.
  • Choose one specific problem to be the project goal.
Learning Outcome

Learn problem scoping and ways to set goals for an AI project.

Activity

Setting Actions Around the Goal

  • List stakeholders involved in the problem.
  • Search for current actions taken to solve this problem.
  • Think around the ethics involved in the goal.
Learning Outcome

Identify stakeholders involved in the problem scoped. Brainstorm on ethical issues.

Activity

Data and Analysis

  • Identify data features needed and sources.
  • Determine frequency of collection.
  • Analyze consequences of insufficient data.
  • Determine validation methods and how analysis informs action.
Learning Outcome

Understand the iterative nature of problem scoping in the AI project cycle.

Presentation

Project Proposal

Presenting the goal, actions, and data plan.

Learning Outcome

Foresee data requirements and analysis. Share student discussions.

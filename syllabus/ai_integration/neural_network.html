Recommended Activity

Creating a Human Neural Network

  • Team Setup: Students split into four teams representing different layers:
    • Input Layer (X students)
    • Hidden Layer 1 (Y students)
    • Hidden Layer 2 (Z students)
    • Output Layer (1 student)
  • Process: Input layer gets data which is passed to hidden layers after some processing.
  • Result: The output layer finally receives all information and produces meaningful information as output.
Learning Outcome

Understand the flow of data through a neural network via gamification.
